# 酒桌摇骰子必应攻略

## README · 导览

> 一句话定位：这不是"运气攻略"，而是一套**把概率算准、把对手读透、把自己演好**的三层实战体系。  
目标读者：酒桌/聚会玩大话骰（吹牛、骗子骰、摇骰子）的普通玩家。  
核心承诺：看完能立刻上桌用，用完能自己复盘涨级。
>

---

### README_1 这套体系在解决什么问题
多数人玩骰子的决策依据是"我感觉"，而高手的决策依据是"三件事的加权结果"：

```plain
  一次叫数决策
        │
        ├──► 【算准】概率底盘 ── 期望水位 / 封顶总量 / 关键阈值
        │              对应板块 1、6
        │
        ├──► 【读透】对手情报 ── 响应速度 / 叫数偏好 / 摇摆与豹子
        │              对应板块 2、3、5
        │
        └──► 【演好】节奏表演 ── 强牌装弱 / 弱牌装强 / 抢答压制
                     对应板块 4
```

**低手犯的错，几乎都是只用了其中一层，或者干脆一层都没用。**

+ 只靠"算"：数字对，但被对手一眼看穿你在数数，反被利用。
+ 只靠"演"：气氛好，但叫数离谱，一开就输。
+ 只靠"猜"：纯赌运气，赢不知怎么赢的，输不知怎么输的。

### README_4 三条贯穿全书的底层心法
**心法一：数字是地基，演技是杠杆。**  
没有概率打底的表演叫瞎蒙，没有表演配合的概率叫透明人。先花一周把板块 1 的水位表背到条件反射，再去练板块 4 的演技。

**心法二：所有信息都是在"叫数的增量"里泄露的。**  
对手叫了什么不重要，重要的是**他比你上一次多叫了几个、快了几秒、换没换点数**。板块 3 整篇都在训练这个观察颗粒度。

**心法三：赢一局靠运气，赢一晚靠记录。**  
人的记忆会自动美化自己的失误。板块 7 的三本笔记（局中速记、赛后复盘、对手档案）是把经验真正转化成能力的唯一通道，也是这套体系里最容易被跳过、但复利最高的一环。

### 本板块速览

### 0_1 学习路径：四阶能力模型
大话骰的能力不是线性增长的，而是分层的。绝大多数人卡在第二阶（会算不会演），一辈子在"懂很多道理但赢不了"的循环里打转。

```plain
  第四阶  控场层  ┃  制造对手的误判，让他主动走进我设的局
  ───────────────╂──────────────────────────────────────
  第三阶  算力层  ┃  实时核算总量，敢喊顶、敢开牌
  ───────────────╂──────────────────────────────────────
  第二阶  读心层  ┃  从响应速度、叫数增量里读出对手手牌
  ───────────────╂──────────────────────────────────────
  第一阶  概率层  ┃  知道叫几个算正常，不叫离谱的数
  ───────────────╂──────────────────────────────────────
                  ┗━━ 必须先夯实下层，上层才立得住
```

**关键判断：你现在在哪一阶？**

| 自检问题 | 答不上来 = 卡在 |
| --- | --- |
| 2 人局，叫"5 个 3"大概有多大概率是真的？ | 第一阶未过 |
| 对手 0.5 秒就接了你的叫数，说明他手牌如何？ | 第二阶未过 |
| 现在场上叫到 6 个 X，我手上 0 个，该开还是该跟？ | 第三阶未过 |
| 我怎么让对手相信我手上没牌，从而主动开我？ | 第四阶未过 |

> 别跳阶。第一阶没打牢就去练演技，结果是"演得很像，但叫的数字本身就不该叫"。
>

### 0_2 新手入门顺序：两周上手路线
#### 第一周：只练"不犯错"
这一周的目标极其克制——**不追求赢，只追求不叫离谱的数、不开没把握的牌。**

| 天 | 训练内容 | 对应板块 | 达标标准 |
| :---: | --- | --- | --- |
| 1-2 | 背下 2 人局的期望水位表 | 板块 1 | 能脱口而出"3 个 X 是正常水位" |
| 3-4 | 局中默算自己手牌的"有效个数" | 板块 1 | 3 秒内算出自己算几个 X |
| 5-7 | 首轮只用逆叫原则，不做复杂操作 | 板块 2 | 首轮不再凭感觉乱叫 |

**第一周的自我禁令：**

+ 禁止在自己手牌很差时硬跟到 4 个以上。
+ 禁止"因为气氛到了"就开牌 —— 开牌必须有数字依据。
+ 禁止在没算清总量时喊超过期望水位 2 个以上的数。

#### 第二周：加入"读人"和"表演"
| 天 | 训练内容 | 对应板块 | 达标标准 |
| :---: | --- | --- | --- |
| 8-9 | 观察对手的接话速度，记录快慢 | 板块 2 / 3 | 能说出"他刚才犹豫了" |
| 10-11 | 练习点数递增试探法 | 板块 3 | 四轮内猜中对手主点数 ≥1 次 |
| 12-13 | 练习强牌装弱（犹豫+调侃+加码） | 板块 4 | 成功诱导对手开牌 ≥1 次 |
| 14 | 第一次完整复盘 | 板块 7 | 填完一张完整复盘表 |

#### 案例小故事：小周的"禁令周"
小周刚学时连输七局，他给自己下了条死命令：**这一周，凡是超过期望水位 2 个以上的叫数，我一律不开也不跟，直接认输。**

结果那一周他输得更快了，但输得"很便宜"——每局都在自己该输的地方认输，没有因为上头而多输。

第二周他放开禁令，突然发现自己能看清很多东西：因为第一周的克制，他养成了"先算后叫"的肌肉记忆。到第 12 天，他第一次靠"强牌装弱"骗到了对手开牌。

> 这个故事的关键不是"输一周就能变强"，而是：**先建立纪律，再谈技巧。** 没纪律的人学技巧，只会把自己骗得更惨。

```plain
  ┌──────────────────────────────────────────────────────┐

  └────────────────────────┬─────────────────────────────┘

                           ▼
  ┌──────────────────────────────────────────────────────┐
  │                     赛 后 复 盘                      │
  │   记录：关键决策点、判断对错、下次怎么做             │
  │   时机：当天，趁记忆还热                             │
  │   作用：把一晚的经验固化成可复用的规则               │

  ┌──────────────────────────────────────────────────────┐
```

### 0_4 训练里程碑：怎么知道自己进步了
不要凭"今晚手感好"来判断进步。用下面四个可量化的里程碑：

| 里程碑 | 达标条件 | 通常所需局数 |
| --- | --- | --- |
| M1 不再乱叫 | 连续 20 局，没有叫出超过期望水位 2 个以上的数 | 20-30 局 |
| M2 能读反应 | 连续 10 局，对对手手牌强弱的判断准确率 ≥60% | 50-80 局 |
| M3 敢算敢开 | 开牌胜率 ≥50%（即开对的时候比对错多） | 80-120 局 |
| M4 能控场 | 能主动设计陷阱，让对手按你的节奏走 | 150 局以上 |

**验证方法**：板块 8 提供了一套完整的验证实验，包括可以自己跑的 100 局概率验证，以及心理博弈的对照清单。别用感觉验证，用数据。

### 0_5 常见学习误区（先看，能省 50 局）
**误区一：背口诀代替理解。**  
"首轮没什么喊什么"背得再熟，不知道背后的概率逻辑，遇到老手改套路就废了。每记一条口诀，必须同时记住"为什么"和"什么时候不适用"。

**误区二：只看自己的牌。**  
新手 90% 的注意力都在自己骰子上。实际上，自己手牌的信息量是**固定**的，对手的信息才是**变量**。高手七成注意力在对手身上。

**误区三：输了归因于运气。**  
连输时下意识想"今天手气不好"。实际上，手气是 50% 的，剩下的 50% 是决策。把每局输的原因写下来，你会发现大部分是决策问题。

**误区四：赢了就不复盘。**  
赢了恰恰是最该复盘的时候——因为赢可能只是运气，如果不搞清楚"这局赢在哪"，下次就会用错误的方法去复制。

## 板块1 · 概率底盘：叫数规则的数学常识
> 本板块目标：把"叫几个算正常"从感觉变成**条件反射**。  
这是整套体系里投入产出比最高的一块——背完这张表，当晚胜率就会有肉眼可见的变化。
>

---

### 本板块速览
+ 一切计算的起点：**有效个数 = 该点数个数 + 1 的个数**。
+ 全场期望个数 = **总骰子数 ÷ 3**；2 人局是 3.33。
+ 2 人局四个关键概率：**3 个 X = 70%、4 个 X = 44%、5 个 X = 21%、6 个 X = 7.7%**。
+ 叫 1 时水位砍半；叫到 6 个 X 以上，"吹牛假设"失效。

---

### 1_1 规则底盘：先统一一套说法
不同酒局的规则有细微差异，上桌前必须花 10 秒确认三件事，否则所有计算都是空中楼阁。

| 规则项 | 常见设定 | 对本手册计算的影响 |
| --- | --- | --- |
| 每人骰子数 | 5 颗（绝大多数） | 本手册所有表格按 5 颗/人计算 |
| 1 是不是万能（斋） | **是**，可当任意点数 | 若"1 不万能"，所有水位下调约一半 |
| 叫 1 时是否翻倍 | 部分规则叫 1 时个数减半或翻倍 | 见 1_4 单独讨论 |

**本手册默认规则**：每人 5 颗骰，1 为万能牌（可当任意点数），叫"N 个 X"表示全场（含自己+所有对手）中，点数为 X 或 1 的骰子总数不少于 N。

> 上桌前一句话确认："1 是万能的吧？" —— 这一句能避免 80% 的规则纠纷。
>

---

### 1_2 核心概念：你的"有效个数"
这是所有计算的起点。拿到骰子后，第一件事不是看点数，而是**算出每个点数的"有效个数"**。

**有效个数 = 该点数的骰子数 + 1 的个数**

举例：我的骰子是 `1 1 3 4 5`

```plain
  我的骰盅：  [1] [1] [3] [4] [5]
                    │
    1 是万能牌，可以变成任何点数
                                            │
        ┌───────────┼───────────┬───────────┐
        ▼           ▼           ▼           ▼
   当成 2 时：   当成 3 时：   当成 4 时：   当成 5 时：
   1+1 = 2个    1+1+3 = 3个   1+1+4 = 3个   1+1+5 = 3个
   （只有两个1）  （两个1+一个3） （两个1+一个4） （两个1+一个5）
                    ▲
              我最强的一门是 3/4/5，各有 3 个
```

**关键推论**：`1 1 3 4 5` 这手牌，我最强的一门有 **3 个**。所以凡是叫"3 个 X"（X 为 3/4/5），我一个人就能扛住一大半。

这就是经典技巧 「1」 里"11345 喊 3 个 2"的底层逻辑——虽然**一个 2 都没有**，但两个 1 可以当 2，所以我个人就贡献了 2 个 2，再需要对面出 1 个 2 就够了。

#### 速算训练（3 秒内完成）
把"有效个数"练成条件反射的方法：

```plain
  第1步：数出 1 的个数 → 记为 A
  第2步：看剩下骰子中最多的是什么点 → 记为 B，出现次数记为 C
  第3步：我的最强门有效个数 = A + C
  第4步：其余点数，看到一次就是 A+1，没看到就是 A

  例：[1][2][2][4][5]  →  A=1, 最强门是2(C=2) → 最强有效个数 = 1+2 = 3
      叫3个4？我只有 1+1 = 2 个（一个1+一个4）
      叫3个3？我只有 1+0 = 1 个（一个1，没有3）
```

### 1_3 期望水位表：几个 X 算"正常"
**这是全书最重要的一张表，建议截图或抄在手机备忘录里。**

在 1 为万能牌、每人 5 颗的规则下，某个点数（非 1）在全场出现的期望个数是：

```plain
  期望个数 = 总骰子数 × (2/6) = 总骰子数 ÷ 3

  为什么是 2/6？
    每颗骰子，是"该点数"或"1"的概率 = 1/6 + 1/6 = 2/6
    例：一颗骰子能贡献"3"的情况 = 掷出3（1/6）或 掷出1（1/6）
```

| 人数 | 总骰数 | 期望个数 | 正常水位（安全线） | 偏高（有支撑） | 危险区（多半是吹） |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 2 人 | 10 颗 | **3.33** | 2-3 个 X | 4 个 X | 5 个 X 以上 |
| 3 人 | 15 颗 | **5.00** | 3-5 个 X | 6 个 X | 7 个 X 以上 |
| 4 人 | 20 颗 | **6.67** | 5-6 个 X | 7-8 个 X | 9 个 X 以上 |
| 5 人 | 25 颗 | **8.33** | 6-8 个 X | 9-10 个 X | 11 个 X 以上 |
| 6 人 | 30 颗 | **10.00** | 8-10 个 X | 11-12 个 X | 13 个 X 以上 |

**怎么用这张表：**

```plain
  对手叫了 N 个 X
        │
        ├─ N ≤ 期望个数 ──────► 大概率是真的，不要轻易开
        │                        （他有牌支撑，开就是送）
        │
        ├─ N = 期望个数 + 1 ──► 有一半可能是真的
        │                        结合他的性格判断
        │
        ├─ N = 期望个数 + 2 ──► 多半在吹，可以开
        │                        （除非他刚摇到豹子）
        │
        └─ N ≥ 期望个数 + 3 ──► 两种可能：
                                「1」 他豹子了（见板块5）
                                「2」 他疯了
                                别慌，见板块 5 的"豹子识别"
```

> **这张表和板块 6 的"开牌决策"是什么关系？**  
上面这套判断是**整体视角**——它回答"场上总共凑得出 N 个 X 吗"，没有把"我自己手上有几个"单列出来。  
而真正决定"该不该开"的，是**板块 6 的 D 值算法**：先扣掉我自己的有效个数 E，算出对手还差几个（D = N - E），再查开牌胜率。  
两者不矛盾，是粗判和精算的关系：**上桌先用这张表做快速体检，真要开牌前再用 D 值算法拍板。**

### 1_5 豹子的概率：为什么"七八个 X"不能随便开
经典技巧 「8」 说"对面喊到七八个 X，说明多半是豹子，忍住不开"。背后的数字是这样的：

豹子 = 一个人手上某点数的"有效个数"达到 4 个以上。

**这里有个极易混淆、但必须分清的双口径问题：**

```plain
  【口径一】摇完后看"我最强的一门"（实战最常用的口径）
    也就是六个点数里取最好的那个

    最强门 ≥4 个（豹子）：     约 21%   ← 每 5 局就有 1 次
    最强门 ≥5 个（超级豹子）：  约  2%   ← 每 50 局 1 次

  【口径二】预先指定一个点数（比如专门看"3"有几颗）

    该点数 ≥3 个：21.0%
    该点数 ≥4 个： 4.5%
    该点数 ≥5 个： 0.4%

  ▼ 两个口径差了 4-5 倍，千万别混用 ▼

    问"我这把摇到豹子了吗"        → 用口径一（21%）
    问"他恰好在 3 上豹子了吗"      → 用口径二（4.5%）
```

**关键推论：**

```plain
  当对手叫到"7 个 X"时（2人局，全场 10 颗）：
    他自己一个人就得贡献 5-6 个 X 才敢这么叫
    → 按口径二，随机情况下这只是 0.4% 的小概率事件

    但"他敢叫"这个行为本身，说明他已经看到了自己的牌
    → 条件概率从 0.4% 被拉高了几十倍

  所以：大数字叫数 ≠ 虚张声势，而是**强手牌的信号**
```

**决策规则：**

+ 正常情况：叫到期望值 +2 就可以考虑开；
+ **但如果叫数已经进入 6 个 X 以上区间（2 人局），先做硬上限验算**：算出 D = N - 我的有效个数 E。
    - **D ≥ 6 → 数学上不可能**（他只有 5 颗骰），直接开，稳赢；
    - D 落在 2~3 → 默认的"吹牛假设"失效，先假设他豹子了，除非有别的证据（详见板块 5 的豹子识别）。

## 板块2 · 开局首轮：虚张声势与第一手读心
> 本板块目标：把开局第一轮打成**情报收集局**，而不是赌博局。  
覆盖经典技巧 「1」（没什么喊什么）、「2」（接得快+1，犹豫就开）、「9」（老手首轮爱骗，手里没有直接开）。

### 本板块速览
+ **逆叫原则**：首轮叫自己最弱的一门，上限是"期望水位 + 1"。
+ **0.8 秒分界线**：秒接 = 有牌；2 秒以上犹豫 = 硬撑。
+ 老手首轮骗术高发，三个条件齐了就开，胜率约 **79%**。
+ **抢答压制**：不给表演型对手酝酿假象的时间。

### 2_1 逆叫原则：手上没什么，就喊什么
#### 规则表述
**首轮叫数时，优先选择自己"有效个数最少"的那个点数来叫。**

这听起来反直觉，但它有三个扎实的理由：

```plain
  理由一：信息不对称最大化
    我手上没有 2 → 我喊"3 个 2" → 对手要扛住，得他自己出 3 个 2
    我手上有 3 个 3 → 我喊"3 个 3" → 对手只需出 0 个，轻松接

    ▼ 同样是叫"3 个 X"，前者把压力全推给对手，后者是送温暖

  理由二：为第二轮留后手
    逆叫之后，如果对手加码，我随时可以
    "跳"回我自己真正强的那门（因为叫数只能往上）
    例：我逆叫 3 个 2，对手叫 4 个 2
       我手上 3 个 3 → 我叫 4 个 3，直接切到我的强项

  理由三：制造"他是不是在吹"的猜疑
    首轮逆叫是老手标志，对手会倾向于认为你有牌
    反而更容易让他保守或误判
```

#### 实操：逆叫三步法
| 步骤 | 动作 | 示例（我的牌 `1 1 3 4 5`） |
| :---: | --- | --- |
| 1 | 算出各点数有效个数 | 2→2个，3→3个，4→3个，5→3个，6→2个 |
| 2 | 挑出**最弱**的门 | 2 和 6 都只有 2 个 |
| 3 | 在期望水位内叫出该点数 | 2 人局期望 3.33 → 叫 **"3 个 2"** |

**这就是技巧中的例子"11345 喊 3 个 2"的完整推导过程。**

#### 逆叫的安全边界
逆叫不是乱叫，必须守住一个底线：

```plain
  逆叫的上限 = 期望水位 + 1

  2 人局：期望 3.33 → 逆叫最多叫到 "4 个 X"
  3 人局：期望 5.00 → 逆叫最多叫到 "6 个 X"

  超过这个数，逆叫就变成了送人头的硬吹
```

**唯一的例外**：如果你摇到了豹子（手上某点数 4 个以上），逆叫原则暂停，改用板块 4 的"豹子双剧本"。

### 2_2 响应时延读心：0.8 秒分界线
经典技巧 「2」 说"如果对方接得快，就 +1；如果对方犹豫，立马开"。这条背后是一条非常可靠的心理学规律：

```plain
  人面对"我手上有牌"和"我手上没牌"时，
  反应时间有系统性差异：

    ┌──────────────────────────────────────────────┐
    │  0 ~ 0.8 秒  │  【秒接】                     │
    │             │  手上有支撑，看一眼就知道能接  │
    │             │  → 我的判断：他这门牌多        │
    │             │  → 我的动作：继续 +1 试探      │
    ├─────────────┼────────────────────────────────┤
    │  0.8 ~ 2秒  │  【正常思考】                  │
    │             │  在算，牌力中等                │
    │             │  → 我的判断：信息不足          │
    │             │  → 我的动作：保持节奏继续加    │
    ├─────────────┼────────────────────────────────┤
    │  2 秒以上   │  【犹豫】                      │
    │             │  在硬撑，或者在演戏            │
    │             │  → 我的判断：他这门牌少        │
    │             │  → 我的动作：果断开牌          │
    └─────────────┴────────────────────────────────┘
```

#### 读时延的三个注意事项
**注意一：要先建立这个人的"基准时延"。**  
有些人天生说话慢，2 秒对他是正常速度。所以第一局先观察他**在正常叫数时**的反应速度，再拿来做对比。**看的是"相对变化"，不是绝对秒数。**

**注意二：警惕"反向表演"。**  
老手会故意在你叫数后停顿两秒，引你开牌。破解方法见 2_4 的"表演识别"。

**注意三：配合叫数增量一起看。**  
单看时延不够准，要把"时延"和"他加了多少"交叉验证：

| 对手反应 | 时延 | 加码幅度 | 综合判断 | 我的动作 |
| --- | :---: | :---: | --- | --- |
| 秒接 + 加 1 个 | 快 | 小 | 手上有货，稳 | 继续试探 |
| 秒接 + 加 2 个 | 快 | 大 | 强牌或有豹子 | 小心，别硬顶 |
| 犹豫 + 加 1 个 | 慢 | 小 | 硬撑，牌不够 | **开！** |
| 犹豫 + 加 2 个 | 慢 | 大 | 多半在演，想吓退我 | 看其他信号，倾向开 |
| 秒接 + 换点数 | 快 | 持平 | 想切回自己的强门 | 记下他换的点数！ |

> 最后一行是重要情报：**对手主动换到的点数，往往就是他手上的强门。** 这是板块 3 递增试探法的前置情报。
>

#### 实操：首轮响应读心的执行流程
```plain
  我叫出 "3 个 2"（逆叫）
        │
        ▼
  ┌────────────────────┐
  │ 对手的反应是什么？ │
  └─────────┬──────────┘
            │
            ├─► 【秒接｜0.8 秒内】他这门有货
            │         └─► 我 +1，叫 "4 个 2"
            │
            ├─► 【正常思考】信息不足，继续观察
            │         └─► 我 +1，叫 "4 个 2"
            │
            ├─► 【犹豫｜2 秒以上】他在硬撑
            │         └─► 立刻开牌
            │
            └─► 【直接加很多】可能是豹子
                      └─► 先观察，见板块 5
```

### 2_3 老手首轮骗术识别：手里没有，直接开
经典技巧 「9」："和老手玩，第 1 轮没有，直接开。举例：对方喊 3 个 5，我没有会立刻开，多半老手第 1 轮会骗人。"

#### 为什么老手首轮爱骗？
```plain
  老手的三个动机：

  1. 试探成本最低
     首轮开牌，输了只丢一次，但能换来
     "这个人开局会开牌"的印象，后面几轮你就被他拿捏

  2. 建立心理优势
     首轮骗成一次，你后面会倾向于相信他"有牌"
     他的后续虚张就有了信用背书

  3. 打乱你的节奏
     你一旦开始怀疑自己的判断，就会犹豫
     而犹豫本身就是最大的破绽
```

#### "手里没有，直接开"的精确执行条件
技巧中说"对方喊 3 个 5，我没有会立刻开"。这里需要补全一个关键前提，否则这条会被误用：

```plain
  ┌───────────────────────────────────────────────┐
  │  直接开牌的三个条件（必须同时满足）           │
  ├───────────────────────────────────────────────┤
  │  「1」 我手上该点数有效个数 = 0 或 1              │
  │     （我贡献不了，压力全在对手身上）          │
  │                                               │
  │  「2」 对手叫数 ≥ 2 人局的期望水位（3.33）        │
  │     即他叫的是 "3 个 X" 及以上                │
  │                                               │
  │  「3」 对手是老手，或有首轮虚张的前科             │
  └───────────────────────────────────────────────┘

  缺任何一个条件，都不要急着开。
  尤其是条件「1」：如果我手上有 2 个有效个数，
  对手叫 3 个 X，他只需出 1 个，太容易了 —— 这时候开必输。
```

#### 概率验算：为什么"我没有 + 他叫 3 个"值得开
2 人局，我手上该点数有效个数为 0：

```plain
  对手 5 颗骰要独立贡献 3 个 X（含万能1，p=1/3）

  P(对手 ≥3 个 X) = 约 21%

  ▼ 结论 ▼
  我开牌的胜率 = 1 - 21% = 79%

  这是一次压倒性有利的开牌
```

如果我手上有 1 个有效个数，对手只需出 2 个：

```plain
  P(对手 ≥2 个 X) = 约 54%
  → 我开牌胜率只有 46%，五五开，不值得开
```

**所以经典技巧的"我没有会立刻开"必须严格理解成"我有效个数为 0"**，有 1 个就只是勉强，有 2 个以上千万别开。

### 2_4 抢答压制：用节奏打断骗子的思路
经典技巧 「9」 后半句："对方喜欢骗人就喊得快点，打断 TA 的节奏思路。"

#### 原理
骗子型选手的核心武器是**表演时间**——他需要 2-3 秒来酝酿一个"我很犹豫但其实我很强"的假象。如果你不给他这个时间，他的武器就废了一半。

```plain
  正常节奏（给骗子表演空间）：
    我："3 个 2"  ──── 2秒 ────  对手：（犹豫表演）"4 个 2"
                          ▲
                     这 2 秒是他的表演窗口

  抢答压制（不给时间）：
    我："3 个 2，你怎么说？"  ─ 0.3秒 ─  对手："……4 个 2"
                                  ▲
                          他来不及设计表演，反应更接近真实
```

#### 抢答压制的三种具体手法
| 手法 | 操作 | 适用场景 |
| --- | --- | --- |
| **连问压迫** | 叫完立刻追问"你呢？""要不要？" | 对手是思考型、慢节奏选手 |
| **快速加码** | 不等他反应完，自己先报下一个数 | 对手习惯用停顿表演 |
| **话题干扰** | 叫数同时聊别的："你昨天那事儿怎么样了，4 个 3" | 对手需要专注才能演 |

#### 抢答的副作用与克制
```plain
  抢答压制不是万能的，有两个副作用：

  「1」 你自己也没时间算数
     → 克制：只在"叫数还在安全水位内"时抢答
            一旦进入 4 个 X 以上，必须慢下来算

  「2」 会激怒对手，让他变得激进
     → 克制：只在对手明显是"表演型"时使用
            对老实人抢答，只会把他逼成拼命三郎
```

### 2_5 案例小故事：三秒定胜负
阿杰和一位公认的"骰子老炮"单挑。第一局，老炮开口就叫"3 个 5"。

阿杰低头看自己的骰子：`2 3 4 4 6` —— 没有 1，没有 5，**5 的有效个数是 0**。

按经典技巧的判断，这属于"老手首轮骗人 + 我手上没有"的典型场景。阿杰没有犹豫，直接掀盅："开。"

老炮的骰子：`1 3 3 5 6` —— 只有 1 个 1 加 1 个 5，共 2 个 5。**阿杰赢了。**

第二局，老炮又叫"3 个 2"。阿杰这把是 `1 2 4 5 6`，2 的有效个数是 2 个（一个 1 + 一个 2）。

阿杰想起"有 1 个就只是勉强，有 2 个千万别开"，忍住了，跟到"3 个 4"（切回自己有 1+1=2 个的门）。老炮犹豫了一下，加到"4 个 4"，阿杰手上 4 的有效个数只有 1+1=2，判断对手需要出 2 个，概率 54%，偏危险——他选择开牌，又赢了。

> **启示**：同样是"对手叫 3 个 X"，第一局有效个数 0 → 开；第二局有效个数 2 → 跟。差别就在**你贡献了多少**。经典技巧的"我没有会立刻开"必须精确到"我有效个数为 0"才成立。

### 3_1 点数递增试探法：他在哪个数上加，他就哪个多
#### 规则表述
技巧中说："TA 喊 3 个 2，我喊 3 个 3，依次增加。对方在哪个数增加，说明 TA 哪个多。"

这条技巧的精髓在于：**用"持平换点"的叫法，逼对手暴露自己的强门。**

#### 为什么"持平换点"能试探出信息
```plain
  关键机制：叫数只能往上走（个数增加，或个数持平但点数变大）

  我叫 "3 个 3" 时，对手有两条路：

    路径 A：加个数 → "4 个 3"
       含义：他愿意在 3 上加码，说明他 3 多

    路径 B：持平换点 → "3 个 4"（或 4/5/6）
       含义：他不想在 3 上加，但愿意换到 4
            说明他 3 不多、4 多

  ▼ 无论他选哪条路，都在泄露信息 ▼

  他"愿意加"的点数 = 他的强门
  他"绕开"的点数   = 他的弱门
```

#### 实操：四轮递增试探法
这是把经典技巧变成可执行流程的版本。**在个数还在安全水位（2 人局 ≤4 个 X）时使用。**

| 轮次 | 我的动作 | 观察对象 | 记录情报 |
| :---: | --- | --- | --- |
| 第 1 轮 | 叫"3 个 2"（逆叫，见板块 2） | 他加个数还是换点数 | 他的第一反应倾向 |
| 第 2 轮 | **持平换点**："3 个 3" | 他是否在 3 上加码 | 若加 → 他 3 多 |
| 第 3 轮 | **持平换点**："3 个 4" | 他是否在 4 上加码 | 若加 → 他 4 多 |
| 第 4 轮 | **持平换点**："3 个 5" | 他是否在 5 上加码 | 若加 → 他 5 多 |

```plain
  信息流向示意：

  我：3个2 ──► 3个3 ──► 3个4 ──► 3个5
                 │        │            │
  他：4个2      4个3     3个4→4个4  3个6
       │          │          │         │
       ▼          ▼          ▼         ▼
     他2多     他3也多？   他在4上加！  他绕开5
                           （重点情报） （他5少）
```

**四轮下来的产出**：一张对手的"点数强弱地图"。有了这张图，你在高个数阶段的开牌判断准确率会大幅提升。

#### 递增试探的三个使用禁忌
```plain
  禁忌一：个数已经超过安全水位，就别再试了
    2人局叫到 5 个 X 还在"持平换点"试探，
    等于拿真金白银买情报 —— 太贵了

  禁忌二：对手已经表现出强牌信号时，停止试探
    他秒接 + 连加两个，说明他豹子了
    这时候该做的是"别硬顶"，见板块 5

  禁忌三：别把自己绕进死路
    持平换点的方向是从小到大（2→3→4→5→6）
    试探到 6 之后就没法再"持平换点"了，
    所以要在换到 6 之前完成情报收集
```

### 3_2 摇摆喊法解码：摇摆 = 他手上 1 多
经典技巧 「4」："边喊边算对面几个 1。如果 TA 几个数摇摆着喊（喊到 5 个数），说明 TA 1 多，要合计下再决定。"

#### 什么是"摇摆喊法"
```plain
  典型的摇摆轨迹（2人局）：

    他："3 个 2"
    他："3 个 4"      ← 换点数，没加个数
    他："3 个 6"      ← 又换点数
    他："4 个 3"      ← 终于加了一个，但换了点数
    他："5 个 5"      ← 继续摇摆着往上

  ▼ 特征总结 ▼
  · 频繁更换点数
  · 个数上涨缓慢（每次 +1）
  · 没有一个点数他愿意连续加码
```

#### 为什么摇摆 = 1 多
这是本手册里最精妙的一条推理，值得完整拆解：

```plain
  前提：1 是万能牌，可以当任何点数

  ┌──────────────────────────────────────────────┐
  │  如果对手手上 1 很多（比如 3 个 1）：        │
  │                                              │
  │   他的"有效个数"在每个点数上都差不多         │
  │   → 3个1 → 叫2有3个、叫3有3个、叫6也有3个    │
  │   → 他不在乎叫哪个点数，因为没有真正的强门   │
  │   → 表现：频繁换点数 = 摇摆                  │
  └──────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────┐
  │  如果对手手上 1 很少，但某点数很多（豹子）：│
  │                                             │
  │   他的"有效个数"高度集中在某一个点数        │
  │   → 他会死守这个点数，反复加码              │
  │   → 表现：不换点数，只加个数                │
  └─────────────────────────────────────────────┘

  ▼ 结论 ▼
  摇摆 = 1 多（万能牌多，但没有绝对强门）
  死守一个点数 = 豹子 或 该点数集中
```

#### 摇摆喊法的反制策略
识别出"他 1 多"之后，该怎么打？**关键是要重新计算概率。**

```plain
  他 1 多意味着什么？
    · 好消息：他没有绝对强门，叫到高位会撑不住
    · 坏消息：他在每个点数上都有保底个数，
              所以"他这门没有"的假设不成立

  ▼ 具体反制 ▼

  策略一：不要赌"他这门没有"
    他 1 多 = 他每门都有保底
    你想着"他不可能有 4 个 5"而去开牌，很可能翻车

  策略二：往高位推，让他自己撑不住
    他没有强门，意味着他加到 5 个 X 以上会很吃力
    主动把个数推高，等他硬撑，再抓他的犹豫（见板块2时延读心）

  策略三：如果他摇到 5 个数还在摇摆，重点核算
    技巧中说"喊到 5 个数，说明 TA 1 多，要合计下再决定"
    → 这时候必须停下来算：
      我自己有几个 + 他可能需要几个 = 总量是否可信
      算法见板块 6 的封顶核算
```

#### 摇摆 vs 死守：一张对照表
| 特征 | 摇摆型（1 多） | 死守型（有强门/豹子） |
| --- | --- | --- |
| 点数变化 | 频繁更换 | 基本不换 |
| 个数涨幅 | 缓慢 +1 | 可能一次 +2 |
| 反应速度 | 叫哪个都差不多快 | 在自己的强门上秒接 |
| 我的应对 | 往高位推，别赌他没有 | 别硬顶，考虑提前脱身 |
| 开牌时机 | 等他加到高位再开 | 等他换到别的点数时开 |

### 3_3 叫数节奏：谁在控制节奏，谁就控制信息流
除了"叫什么"，**"多快叫出来"本身就是一种武器**。这一节把节奏问题系统化。

#### 三种节奏及其效果
```plain
  ┌───────────────────────────────────────────────────┐
  │  【快节奏 · 压制型】                              │
  │  操作：叫完立刻追问，不等对手思考                 │
  │  效果：压缩对手的表演时间，逼出真实反应           │
  │  适用：对手是表演型、思考型                       │
  │  禁忌：个数进入高位时不要用（自己也需要算）       │
  ├───────────────────────────────────────────────────┤
  │  【慢节奏 · 施压型】                              │
  │  操作：叫数前故意停顿、叹气、再叫                 │
  │  效果：制造"我很为难"的假象（见板块4装弱）        │
  │  适用：我手牌强，想诱对手开牌                     │
  │  禁忌：真牌弱时别用，会弄巧成拙显得心虚           │
  ├───────────────────────────────────────────────────┤
  │  【变速节奏 · 扰乱型】                            │
  │  操作：时而秒接，时而长考，不给你规律             │
  │  效果：让对手无法建立"我的基准反应"               │
  │  适用：对手在认真读我的反应                       │
  │  禁忌：会让自己显得"很会玩"，引来针对性打法       │
  └───────────────────────────────────────────────────┘
```

#### 节奏战的核心原则
**原则一：先摸清对手的节奏，再决定用哪种节奏。**  
第一局先保持中性节奏，观察对手是快是慢、是稳是变。

**原则二：节奏要"反着来"。**

+ 对手快 → 我慢下来，打断他的惯性；
+ 对手慢 → 我快一点，不给他表演时间（这就是经典技巧的"喊得快点，打断 TA 的节奏思路"）。

**原则三：关键决策点必须主动夺回节奏。**  
当叫数接近自己判断的临界点时，无论之前什么节奏，**一定要慢下来算清楚**。这时候"演"是次要的，"对"才是主要的。

### 3_5 案例小故事：一次试探省下三杯酒
小林和同事单挑，前两轮他一直用递增试探。

→ 情报：同事在 3/5 上都绕开了，属于**摇摆型**。

> **启示**：小林赢在**没有在中期就急着开牌**。他知道同事是摇摆型（1 多），所以放弃了"赌他没有"的打法，改用"推到他撑不住"的打法。这就是经典技巧"要合计下再决定"的正确打开方式。

**本板块要点：**

1. **递增试探法**：用"持平换点"逼对手在强门上加码、在弱门上绕开，四轮画出点数强弱地图。个数超过安全水位就停止试探。
2. **摇摆解码**：摇摆 = 1 多 = 每门都有保底但没有绝对强门。对付摇摆型不要赌"他没有"，要往高位推到他撑不住。
3. **节奏控制**：快节奏压制表演型对手，慢节奏施压诱开，变速节奏防被读。原则是"反着来"。
4. **点数地图**：把情报汇总成表，随局数累积，是指数级增值的资产。

## 板块4 · 心理表演术：强弱互换的演技
> 本板块目标：让你的手牌实力和对手看到的表象**脱钩**。  
覆盖经典技巧 「2」（骰子好时犹豫一会再加）、「5」（摇到豹子使劲喊 / 或假装示弱 +1）。
>

---

### 本板块速览
+ **强牌装弱三段式**：犹豫 → 调侃 → 加码，最后一步**低头、不对视**。
+ **豹子双剧本**：保守对手用 A（豪放强攻），激进对手用 B（示弱诱开）。
+ 弱牌装强是它的对偶，但**一晚最多用 2-3 次**，否则信用透支。
+ 情绪三条：赢不露喜、输不露急、决策节奏保持一致。

### 4_1 强牌装弱：犹豫 + 调侃 + 加码的三段式
#### 场景还原
> "自己是 12245，TA 喊 4 个 2，可以假装犹豫并且调侃'都 4 个 2 啦'然后再加一个，TA 会觉得你没那么多，会开。"
>

先把这个场景算清楚，再看演技：

```plain
  我的牌：[1][2][2][4][5]
    → 1 的个数 = 1
    → 2 的个数 = 2
    → 我的 2 的有效个数 = 1 + 2 = 3 个

  对手叫 "4 个 2"
    → 全场需要 4 个 2，我已经有 3 个
    → 对手只需出 1 个 2（概率约 60%）
    → 这手牌我在 2 上非常强

  我加一个 → 我叫 "5 个 2"
    → 全场需要 5 个 2，我有 3 个
    → 对手需要出 2 个 2（概率约 54%）
    → 仍然是可打的牌

  ▼ 演技的目的 ▼
  让对手相信"我在硬撑"，从而主动开牌
  一旦他开，我手上 3 个 2 的底子就有极大概率兑现
```

#### 三段式演技拆解
```plain
  ┌─────────────────────────────────────────────────────┐
  │  第 1 段：犹豫（2-3 秒）                            │
  │                                                     │
  │  动作：低头看骰盅、皱眉、手指敲桌、叹气             │
  │  潜台词："我手上的 2 不太够，这个数有点勉强"        │
  │  要点：犹豫要给足时间，让对手看清楚你的为难         │
  ├─────────────────────────────────────────────────────┤
  │  第 2 段：调侃（语言施压）                          │
  │                                                     │
  │  话术："都 4 个 2 啦？""你这也太狠了吧"             │
  │       "行吧行吧……那我……5 个 2"                      │
  │  潜台词："我是被迫跟的，不是我主动想叫"             │
  │  要点：语气要带无奈，不要带挑衅                     │
  ├─────────────────────────────────────────────────────┤
  │  第 3 段：加码（动作要"虚"）                        │
  │                                                     │
  │  动作：声音稍微放低、语速放慢、说完不抬头           │
  │  潜台词："我也心虚，你要开就开吧"                   │
  │  要点：加完码之后**不要**看对手的眼睛               │
  │        （对视会被解读为挑衅，反而降低他开牌意愿）   │
  └─────────────────────────────────────────────────────┘
```

#### 为什么"我越虚，他越想开"
```plain
  对手开牌的心理门槛：
    他需要判断"我大概率没有"才会开

  当我表现出犹豫时：
    他的判断 = "他没那么多" + "他心虚"
    → 开牌意愿大幅上升

  而实际上我手上有 3 个 2：
    → 他开牌 = 我有极大概率赢

  ▼ 这就是"诱开"战术 ▼
  把开牌的主动权交给对手，
  但我提前确保了自己能扛住
```

#### 强牌装弱的适用条件
**不是所有强牌都适合装弱，必须满足：**

| 条件 | 要求 | 原因 |
| --- | --- | --- |
| 「1」 我有效个数 ≥ 对手叫数 - 1 | 他叫 4 个，我至少有 3 个 | 他开牌时我能扛住 |
| 「2」 加码后仍在可承受范围 | 我叫 5 个，他需出 2 个（54%） | 他不开而继续加，我也不至于立刻崩 |
| 「3」 对手是"会开牌"的类型 | 不能是死也不开的老实人 | 装弱的目的是诱开，他不开就白演了 |

**禁忌：真牌弱时装弱 = 双重打击。**  
手上没牌还装犹豫，一旦对手真开了，你输得一点悬念都没有。而且装弱时的犹豫，会和真正的犹豫混在一起，破坏你以后装弱的可信度。

### 4_2 豹子双剧本：豪放强攻 vs 示弱诱开
经典技巧 「5」："摇到豹子，使劲大胆的喊，不要怂。天助我，使劲大胆喊。或者假装示弱，弱弱的 +1，迷惑对方。"

经典技巧给了两个看似矛盾的选项。其实**它们不是二选一，而是按对手性格选择的两套剧本。**

#### 先确认：什么叫豹子
```plain
  豹子 = 手上某点数的"有效个数"达到 4 个以上

  例：[1][3][3][3][6]  →  3 的有效个数 = 1+3 = 4 个  ← 豹子
      [3][3][3][3][5]  →  3 的有效个数 = 4 个        ← 豹子
      [1][1][2][2][2]  →  2 的有效个数 = 2+3 = 5 个  ← 超级豹子

  概率参考（个人 5 颗骰，按"最强的一门"计）：
    最强门 ≥4 个（豹子）：     约 21%   每 5 局出现 1 次
    最强门 ≥5 个（超级豹子）： 约  2%   每 50 局出现 1 次

  注：若限定"预先指定的某个点数"（比如只在乎 3），
      ≥4 个的概率仅 4.5% —— 两个口径别混用，
      详见板块 1 的双口径说明。

  ▼ 实战含义 ▼
  豹子并不罕见：每 5 局你就有 1 次能摸到豹子。
  所以豹子剧本（剧本 A / 剧本 B）是**高频技能**，
  必须提前练熟，不能临场才想。
```

#### 剧本 A：豪放强攻（使劲大胆喊，不要怂）
```plain
  ┌────────────────────────────────────────────────┐
  │  操作：直接跳叫，一次把个数拉高 1-2 个         │
  │  话术："5 个 3，敢不敢？"                      │
  │  神态：自信、干脆、眼神直视                    │
  │                                                │
  │  目的：用气势压住对手，让他不敢跟              │
  └────────────────────────────────────────────────┘

  适用对手：
    √ 保守型（容易被大气势吓退）
    √ 新手（对高个数天然恐惧）
    √ 已经连输几局、心态变紧的人

  风险：
    × 遇到同样有牌的对手，会被反将
    × 遇到爱开牌的对手，等于主动暴露
```

#### 剧本 B：示弱诱开（弱弱地 +1）
```plain
  ┌───────────────────────────────────────────────┐
  │  操作：每次只 +1，配犹豫、小声、无奈语气      │
  │  话术："那……4 个 3 吧……"                      │
  │  神态：心虚、不抬头、动作慢                   │
  │                                               │
  │  目的：让他觉得我在硬撑，主动开牌             │
  └───────────────────────────────────────────────┘

  适用对手：
    √ 激进型（喜欢开牌的人）
    √ 自负型（觉得自己能看穿你）
    √ 已经赢了几局、心态放松想继续赢的人

  风险：
    × 遇到保守型，他不开，你得自己一路加
      加到高位后反而可能被他抓
```

#### 双剧本选择决策树
```plain
  我摇到豹子（最强门 ≥4 个）
        │
        ├─► 对手是【保守型 / 新手】
        │         └─► 剧本 A：豪放强攻，一次拉高 1-2 个
        │
        ├─► 对手是【激进型 / 爱开牌 / 自负】
        │         └─► 剧本 B：示弱诱开，每次只 +1
        │
        └─► 对手是【老手 / 会读人】
                  └─► 混合剧本：先 A 立威，后 B 收割
```

#### 对老手的"混合剧本"
对付会读人的老手，单一剧本会被识破。正确做法是**制造矛盾信号**：

```plain
  第 1-2 轮：剧本 A —— 大声叫、气势足
    目的：建立"这人摇到好牌就很嚣张"的印象

  第 3 轮起：剧本 B —— 突然变小声、犹豫
    目的：他会以为"这次他没牌了"，从而开牌

  ▼ 关键 ▼
  你其实一直有豹子，但他被你的"前后反差"骗了
  老手最怕的不是一致性，而是无法归类
```

### 4_3 反向应用：弱牌装强
经典技巧的九条没直接讲这条，但它是强牌装弱的对偶技术，而且在实战中同样高频。

```plain
  场景：我手上很烂，但我不想输

  操作：
    · 叫数干脆利落，不犹豫
    · 主动加码，甚至跳叫
    · 语气轻松、甚至带点挑衅

  目的：
    · 让对手误判我有牌，不敢开
    · 逼他自己加到高位，然后由我开牌（或他崩）

  ⚠ 道德与效果边界：
    这是纯粹的心理博弈，不违规
    但代价是"信用透支"——
    装强次数太多，以后真有牌时没人信你
```

**装强的成本控制原则：**

```plain
  一晚之内，装强不超过 2-3 次
  且每次装强后，如果成功了，
  下一轮要主动回归"老实"的叫法

  这样才能维持"我的表演可信度"这个长期资产
```

### 4_4 语言杠杆：话术库与情绪管理
#### 常用话术库（按目的分类）
| 目的 | 话术示例 | 使用时机 |
| --- | --- | --- |
| **装弱** | "都 4 个 2 啦……那我 5 个 2 吧" | 强牌，想诱开 |
| **装弱** | "你这也太狠了，我接不动啊" | 强牌，配犹豫 |
| **施压** | "5 个 3，你敢跟吗？" | 豹子，剧本 A |
| **施压** | "别磨了，直接说要不要" | 抢答压制时 |
| **误导** | "我 2 特别少"（真话反说） | 只在对手完全不熟时有效 |
| **脱身** | "这把给你，下一把认真了" | 烂牌，主动认输保节奏 |

> 注意"真话反说"（"我 2 特别少"）风险极高，只在对手完全不熟悉套路时用。对老手说这种话，等于直接告诉他你在演。**本手册不推荐把它当作常规武器。**
>

#### 情绪管理：三个必须守住的状态
```plain
  状态一：赢不露喜
    赢牌后立刻收住表情，不嘲讽、不嘚瑟
    原因：对手一旦被激怒，会变得更激进、更难读
          而你需要的恰恰是他保持原有节奏

  状态二：输不露急
    连输时手不要抖、语速不要变快
    原因：急躁是最好读的破绽，老手一眼看穿
          而且急躁会让你跳过计算步骤

  状态三：全程保持"决策节奏一致"
    无论牌好牌坏，拿起骰盅到叫数的时间间隔保持稳定
    原因：这是防止被"时延读心"（板块2）反制的根本方法
          —— 你要读对手，就先别让对手读到你
```

### 4_5 案例小故事：一场演砸的和一场演成的
**演砸的那次：**  
小赵第一次学"强牌装弱"，拿到 `[1][2][2][4][5]`，对手叫"4 个 2"，他有 3 个 2。

他按教程开始演：低头、皱眉、叹气，说了句"都 4 个 2 啦"，然后加码"5 个 2"。

问题出在最后一步——**他说完抬头直勾勾盯着对手，还补了一句"你敢开吗"**。

对手本来想开的，被这一盯一激，反而改了主意："行，那我 6 个 2。"

小赵只有 3 个 2，6 个 2 需要对手出 3 个，概率只有 21%。他被迫开牌，输了。

> **教训**：装弱的第三段"加码"必须做全套——**说完不要对视、不要挑衅**。任何一点挑衅都会把对手从"想开"推回"不敢开"。
>

**演成的那次：**  
同一个小赵，两周后又拿到类似的牌。这次他学乖了：犹豫、调侃"都 4 个 2 啦"、小声说出"5 个 2"，然后把骰盅往桌上一放，**低头去拿饮料，全程没看对手一眼**。

对手观察了他三秒，掀盅："开。"

小赵 3 个 2，对手 2 个 2，加起来 5 个 —— **小赵赢。**

> **启示**：演技的胜负手往往不在"演了什么"，而在**细节的完整性**。一个多余的眼神，就能让整场表演全部作废。
>

### 4_7 板块小结
**本板块要点：**

1. **强牌装弱三段式**：犹豫（2-3 秒）→ 调侃（无奈语气）→ 加码（低头、不对视、不挑衅）。目的是把开牌权交给对手，而我提前确保能扛住。
2. **装弱的三个前提**：我有效个数 ≥ 对手叫数 -1；加码后仍可承受；对手是会开牌的类型。真牌弱时绝不装弱。
3. **豹子双剧本**：保守/新手 → 剧本 A 豪放强攻；激进/自负 → 剧本 B 示弱诱开；老手 → 混合剧本，先 A 立威后 B 收割。
4. **弱牌装强**是强牌装弱的对偶，但一晚最多用 2-3 次，否则透支信用。
5. **情绪管理三条**：赢不露喜、输不露急、全程保持决策节奏一致。

## 板块5 · 对手画像与反制剧本
> 本板块目标：把"看人下菜"从玄学变成**有分类、有剧本、有触发条件**的操作系统。  
覆盖经典技巧 「6」（对面上来就喊 1，直接开）、「7」（对面喊到七八个 X，忍住不开）、「9」（和老手玩的差异化打法）。
>

---

### 本板块速览
+ **四象限分类**：C 保守 < A 莽撞 < B 攻击 < D 控场（难度递增）。
+ **开口喊 1** 多半是虚张，但我自己 1 少时才敢开。
+ **大数字不慌**：先算硬上限 D = N - E，D ≥ 6 直接开；D = 2~3 时"吹牛假设"才失效，先假设豹子。
+ 打新手靠**气势压制**，打老手靠**抢节奏 + 破表演**。

### 5_1 对手四象限：先分类，再出招
所有对手都可以按两个维度归类：**叫数风格**（激进/保守）× **技术层级**（新手/老手）。

```plain
                        技 术 层 级
             新手 ─────────────────► 老手
             │                        │
   激   ┌────┴─────┐          ┌───────┴─────┐
   进   │  A 莽 撞 型 │          │  B 攻 击 型  │
   │    │           │          │             │
   叫   │ 乱叫、爱开 │          │ 会算、会压   │
   数   │ 破绽极多   │          │ 最难对付     │
   风   ├───────────┤          ├─────────────┤
   格   │  C 保 守 型 │          │  D 控 场 型  │
   │    │           │          │             │
   保   │ 不敢叫不敢开│          │ 会演、会诱   │
   守   │ 容易被吓退 │          │ 最会读人     │
             │                        │
             └────────────────────────┘

  对付难度的真实排序（从好打到难打）：
    C 保守型  <  A 莽撞型  <  B 攻击型  <  D 控场型
```

| 类型 | 识别特征 | 核心破绽 | 主战剧本 |
| :---: | --- | --- | --- |
| **C 保守型** | 叫数偏低、很少主动加、开牌犹豫 | 一压就退、不敢跟高位 | 气势压制 + 高位逼退 |
| **A 莽撞型** | 叫数忽高忽低、爱开牌、凭感觉 | 数字没逻辑、破绽全写在动作上 | 稳守 + 等他自己崩 |
| **B 攻击型** | 叫数有算计、节奏快、爱抢答 | 太依赖压制，遇到硬茬会冒进 | 反抢答 + 诱他冒进 |
| **D 控场型** | 会演、节奏多变、话术多 | 表演痕迹重、反差处有破绽 | 破表演 + 不给他归类 |

### 5_2 反制剧本一：对面上来就喊 1，直接开
经典技巧 「7」："对面上来就喊 1，建议直接开，如果自己 1 多，当我没说。"

#### 概率依据：为什么开口喊 1 值得怀疑
回顾板块 1 的数据（2 人局，10 颗骰，叫 1 时 1 不万能，p = 1/6）：

```plain
  叫 1 个 1：83.8%  →  几乎必中，没有叫的价值
  叫 2 个 1：51.5%  →  五五开，最常见的正常开叫
  叫 3 个 1：22.5%  →  只有两成真
  叫 4 个 1： 7.0%  →  基本可以断定是吹
  叫 5 个 1： 1.5%  →  除非他手上有 3 个以上的 1

  ▼ 关键观察 ▼
  2 人局叫 1 的期望只有 1.67 个
  所以"正常"的开叫是 2 个 1
  → 开口就叫 3 个 1 及以上的，多半在虚张
```

#### 执行条件（经典技巧的例外必须精确化）
```plain
  ┌───────────────────────────────────────────────┐
  │  "直接开" 的触发条件：                        │
  │                                               │
  │   「1」 对手开叫 ≥ 3 个 1（2人局）                │
  │      或 ≥ 4 个 1（3人局）                     │
  │                                               │
  │   「2」 我手上的 1 的个数 ≤ 1                     │
  │      （这就是经典技巧的"如果自己1多，当我没说"）  │
  │                                               │
  │  两条同时满足 → 直接开                        │
  └───────────────────────────────────────────────┘

  为什么条件「2」这么重要？
    我手上有 2-3 个 1 时，对手叫 3 个 1 是很容易达成的
    这时候开牌，等于送

  快速核算（叫 1 时 1 不万能，p = 1/6）：
    对手叫 N 个 1，我手上有 M 个 1
    → 对手需要出 (N - M) 个 1
    → 他 5 颗骰出这么多个 1 的概率 / 我开牌胜率：

      需出 1 个：59.8%   →  我开牌胜率 40.2%
      需出 2 个：19.6%   →  我开牌胜率 80.4%   *
      需出 3 个： 3.6%   →  我开牌胜率 96.4%   **

  ▼ 对比：叫非 1 的点数时（1 万能，p = 1/3） ▼
      需出 1 个：86.8%   →  我开牌胜率 13.2%
      需出 2 个：53.9%   →  我开牌胜率 46.1%
      需出 3 个：21.0%   →  我开牌胜率 79.0%

  可以看出：叫 1 时"需出 2 个"就已经有 80% 的开牌胜率，
  而叫普通点数时"需出 3 个"才刚到 79%。
  这就是"喊 1 特别容易翻车"的数学原因。
```

#### 开口喊 1 的三种意图
```plain
  意图一：试探（最常见）
    他不确定你懂不懂规则，用喊 1 试水
    → 反制：直接开，教他做人

  意图二：虚张声势（老手爱用）
    他知道你不敢开 1（因为 1 看起来"少"）
    → 反制：按条件直接开

  意图三：真有牌（他自己 1 多）
    他手上有 3 个 1，叫 3 个 1 很安全
    → 识别：他叫完很淡定、秒接你的加码
    → 反制：这时候别开，改叫别的点数脱身
```

#### 喊 1 的"安全上限"速查
| 人数 | 叫 1 的期望 | 正常开叫 | 可疑线 | 基本可开 |
| :---: | :---: | :---: | :---: | :---: |
| 2 人 | 1.67 | 2 个 1 | 3 个 1 | 4 个 1 |
| 3 人 | 2.50 | 2-3 个 1 | 4 个 1 | 5 个 1 |
| 4 人 | 3.33 | 3 个 1 | 5 个 1 | 6 个 1 |

### 5_3 反制剧本二：对面喊到七八个 X，忍住不开
经典技巧 「8」："对面喊道七八个 X 的时候，说明多半是豹子，忍住不开。"

#### 为什么"越大越不能开"
这条违背直觉，但数字支持它。关键在于**条件概率的翻转**：

```plain
  一般情况下的假设：
    "叫得越高 = 越可能在吹"

  但当叫数进入极端高位时，这个假设失效：

  ┌──────────────────────────────────────────────┐
  │  2人局，对手叫 "7 个 X"（总骰 10 颗）        │
  │                                              │
  │  随机情况下，7 个 X 的真实概率只有 2.0%      │
  │                                              │
  │  但他为什么敢叫？                            │
  │    → 因为他看到了自己的牌                    │
  │    → 他一个人就得有 5-6 个 X 才敢这么叫      │
  │                                              │
  │  换句话说：                                  │
  │  "叫 7 个 X" 这个行为本身，                  │
  │  已经把"他豹子"的概率从 1% 拉到了 70%+       │
  └──────────────────────────────────────────────┘

  ▼ 这就是贝叶斯直觉 ▼
   witnessed 行为会彻底改变概率分布
```

#### 先做一道"硬上限"验算：他凑得出来吗？
在讨论"忍住不开"之前，必须先做一步**纯算术检查**——因为对手手上只有 5 颗骰，他能贡献的个数存在物理上限。

```plain
  硬上限公式：  对手最多贡献 5 个 X（他只有 5 颗骰）

  所以：  D = 他叫的数 N - 我的有效个数 E

    D ≥ 6  ──►  数学上不可能！他就算摇出天牌也凑不出来
                → 百分之百是虚张，直接开，稳赢
    D = 5  ──►  他要 5 颗骰全部有效（概率 0.4%）
                → 直接开
    D = 4  ──►  概率 4.5%，直接开
    D = 3  ──►  概率 21.0%，开（我胜率 79%）
    D = 2  ──►  概率 53.9%，五五开，看情报
    D ≤ 1  ──►  别开
```

**这一步能救回很多"被唬住"的局。**举例：

```plain
  2 人局，我手上 3 的有效个数 = 0，他叫 "6 个 3"
    D = 6 - 0 = 6  ≥ 6
    → 他最多只有 5 颗骰，凑不出 6 个 3
    → 不管他是不是豹子，这个叫数都不成立
    → 直接开，必胜

  同样是我 0 个，他叫 "5 个 3"
    D = 5 - 0 = 5
    → 他要 5 颗骰全是 3 或 1，概率 0.4%
    → 直接开
```

> **这条修正很重要**：经典技巧的"喊到七八个 X 就忍住不开"，只有在**你自己这门牌很多**（E 大、D 小）的时候才成立。如果你自己一个都没有，那恰恰是最好开的局面——不是他太强，是他吹过了物理上限。
>

#### 决策规则：大数字叫数的"三不原则"
经过硬上限验算、确认 D ≤ 3 之后，才适用下面的三不原则：

```plain
  ┌────────────────────────────────────────────────┐
  │  当 D 落在 2 ~ 3 之间（即"他可能真有"的区间）：│
  │                                                │
  │  一不：不轻易开                                │
  │        先假设他豹子，除非有反证                │
  │                                                │
  │  二不：不硬顶                                  │
  │        不要为了"气势"继续往上加                │
  │                                                │
  │  三不：不慌                                    │
  │        大数字不等于必输，                      │
  │        你还有"跟到他自己崩"的选项              │
  └────────────────────────────────────────────────┘
```

#### 怎么分辨"真豹子"和"极限虚张"
```plain
  真豹子的信号（越多越可信）：
    √ 他叫完很淡定，甚至不看骰盅
    √ 他是从低位数一步步加上来的，不是跳叫
    √ 他在这个点数上从头到尾没换过（死守型，见板块3）
    √ 他被你质疑时毫不退让

  极限虚张的信号：
    × 他是跳叫上去的（从 4 个直接跳到 7 个）
    × 他这次叫数前犹豫了很久
    × 他之前在多个点数间摇摆过（说明 1 多，不是豹子）
    × 他说了很多话（话多 = 心虚，需要语言补位）

  如果虚张信号 ≥2 个 → 可以开
  如果豹子信号 ≥2 个 → 忍住，跟他或认输
```

#### 遇到真豹子时的体面脱身
```plain
  确认他豹子了，硬拼没意义，正确做法：

  选项一：主动认输（最省成本）
    "这把给你，你豹子了吧"
    → 保住心态，也保住后面的局

  选项二：跟他一轮，逼他自己加过头
    他叫 7 个 X，你叫 7 个 Y（换个他还行的点数）
    如果他真豹子，他会继续加到 8 个 X
    这时候你再开，或者等他叫到不可信的地步

  选项三：换点数反打
    如果你自己也有一个强门（4个以上），
    可以在你的强门上跟他硬碰

  ⚠ 别做的事：明知他豹子还为了面子死跟
```

### 5_4 反制剧本三：老手 vs 新手的差异化打法
经典技巧 「9」 的核心判断是"和老手玩，第 1 轮没有，直接开"。这一节把它扩展成完整的差异化策略。

#### 对新手（C 保守型 / A 莽撞型）
```plain
  新手的三个特点：
    1. 不背水位，叫数凭感觉
    2. 表演经验少，反应比较真实
    3. 容易被气势影响

  ▼ 打法 ▼

  首选：气势压制
    · 叫数干脆、声音稳、不犹豫
    · 适度跳叫，制造压迫感
    · 他会倾向于保守，不敢跟到高位

  次选：诱他冒进
    · 偶尔示弱，引他开牌
    · 新手开牌往往凭冲动，容易被诱

  禁忌：
    × 不要用复杂的递增试探（他没规律，试探不出东西）
    × 不要用混合剧本（他读不懂，白演）
```

#### 对老手（B 攻击型 / D 控场型）
```plain
  老手的三个特点：
    1. 会算，叫数在水位内
    2. 会演，反应不可信
    3. 在读你，也在防你读他

  ▼ 打法 ▼

  首选：抢节奏（经典技巧的"喊得快点，打断节奏"）
    · 压缩他的表演时间，逼出真实反应
    · 变速节奏，不让他建立你的基准

  次选：首轮严格执法
    · 他首轮叫数 + 我有效个数 = 0 → 直接开
    · 老手首轮骗术概率高，见板块 2

  第三：破他的表演
    · 他的表演必有"反差点"，从反差点入手
    · 例：他平时很稳，突然话多 → 心虚

  禁忌：
    × 不要跟他拼演技（他练得比你多）
    × 不要被他的话术带节奏
    × 不要因为他"看起来很强"就不敢开
      他的强是演出来的，数字才是真的
```

#### 老手识别清单（5 秒内判断）
| 信号 | 说明 |
| --- | --- |
| 上桌先问"1 是不是万能" | 懂规则，有基础 |
| 叫数稳定落在期望水位附近 | 会算 |
| 反应时间刻意保持一致 | 防读心，老手标志 |
| 会主动换点数试探你 | 在用递增试探法 |
| 输了不慌、赢了不张扬 | 情绪管理过关 |

**命中 3 条以上 → 按老手剧本打。**

### 5_5 案例小故事：一次"忍住不开"的价值
大刘和一位朋友单挑，朋友一路叫到"7 个 3"。

大刘手上 `2 4 5 6 6`，3 的有效个数是 **0**。按"常识"，7 个 3 需要朋友一个人出 7 个，这几乎不可能——大刘第一反应是"开！"

但他想起了经典技巧 「8」："对面喊到七八个 X，说明多半是豹子。"

他忍住，改叫"7 个 6"（自己有两个 6），想试探一下。

朋友几乎没有思考，脱口而出："8 个 3。"

这个反应让大刘确认了：

+ 朋友从头到尾**没换过点数**（死守型）；
+ 被换点数试探时**毫不退让**（真豹子信号）；
+ 反应速度极快（有牌支撑）。

大刘果断认输："你豹子了吧，这把给你。"

朋友掀盅：`1 3 3 3 3` —— 3 的有效个数 5 个。**果然是豹子。**

如果大刘当时冲动开了，不但输这一局，还会因为"被反杀"而心态失衡，后面可能连输好几局。

> **启示**：忍住不开省下的不只是这一局的酒，更是**心态**。认输一次便宜的，比赌一次贵的划算。
>

### 5_7 板块小结
**本板块要点：**

1. **对手四象限**：C 保守 < A 莽撞 < B 攻击 < D 控场（难度递增），先分类再出招。

## 板块6 · 终局算力：敢喊顶、敢开牌
> 本板块目标：把前五个板块的所有情报，收敛成最后一个动作——**开还是不开，喊到哪里为止**。

### 本板块速览
+ **总量公式**：我的有效个数（精确）+ 对手推测个数（估算）。
+ **顶格收网**：算准总量后叫顶格数，他跟或加我都不亏。
+ **开牌三步**：算 E → 算 D → 查表，**只有 D ≥ 3 才值得果断开**。
+ 临界点三线：数字临界、情报临界、反应临界。

### 6_1 总量封顶算法：算清"场上到底有几个 X"
所有终局判断的起点，都是同一个公式：

```plain
  ┌───────────────────────────────────────────────────┐
  │                                                   │
  │    总量估计 = 我的有效个数 + 对手的推测个数       │
  │                                                   │
  │    其中：                                         │
  │    · 我的有效个数 = 该点数个数 + 1 的个数（精确） │
  │    · 对手的推测个数 = 由前面几轮情报推断（估算）  │
  │                                                   │
  └───────────────────────────────────────────────────┘

  对照基准（2人局）：
    期望总量 = 10 颗 ÷ 3 = 3.33 个

    如果我的总量估计明显 > 3.33  →  这门偏强，可以继续推
    如果我的总量估计 ≈ 3.33      →  中等，加码需谨慎
    如果我的总量估计 < 3.33      →  这门偏弱，考虑换点数或开牌
```

#### 对手推测个数怎么估
这是最难的一步，但可以系统化。三个信息源按可靠性排序：

```plain
  可靠性 高
     │
     │  「1」 他的叫数行为（最可靠）
     │     · 他在哪个点数上加码 → 那个点数他多
     │     · 他绕开哪个点数     → 那个点数他少
     │     · 摇摆还是死守       → 死守的点数他多
     │
     │  「2」 他的反应时延
     │     · 秒接 → 他有支撑，按"他有 2 个以上"估
     │     · 犹豫 → 他撑不住，按"他 0-1 个"估
     │
     │  「3」 概率基准（兜底）
     │     没任何情报时，他某点数的期望 = 5 ÷ 3 ≈ 1.67 个
     ▼
  可靠性 低
```

**实用估值表（2 人局，对手 5 颗骰）：**

| 观察到的信号 | 对手该点数估几个 |
| --- | --- |
| 他在这个点数上连加 2 次以上 | 3-4 个（可能豹子） |
| 他秒接且在这个点数上加 1 | 2-3 个 |
| 他在这个点数上持平换点过 | 1-2 个 |
| 他绕开这个点数，从不主动叫 | 0-1 个 |
| 无任何情报 | 1.67 个（取 2） |

### 6_2 顶格收网：算准了就敢喊到顶
经典场景的完整还原：

> "感觉喊到顶了。算到两个人一共 6 个 3，自己再加对面一定开的话，可以喊。"
>

#### 这句话的精确解读
```plain
  前提：我算出场上 3 的总量 = 6 个
        （比如我自己 4 个 + 推测他 2 个）

  ┌─────────────────────────────────────────────┐
  │  那么 "6 个 3" 就是这门点数的【顶格真实数】 │
  └─────────────────────────────────────────────┘
                                                │
                    ▼
  我喊 "6 个 3"  →  这是一个真实成立的叫数
                                                │
        ┌───────────┴───────────────────────────┐
        │                                       │
        ▼                       ▼
   他不敢加，开我         他加到 "7 个 3"
   → 我赢（6个真实）      → 7 个 3 不成立（我算过总量只有6）
                          → 我开他，我赢

  ▼ 这就是"顶格收网" ▼
  算准了顶格数，无论他跟还是加，我都不亏
```

#### 顶格收网的三步执行法
| 步骤 | 动作 | 检查点 |
| :---: | --- | --- |
| **1. 核算** | 我的有效个数 + 对手推测个数 = 总量估计 | 对手推测是否有情报支撑？没有就别用这招 |
| **2. 叫顶** | 叫出"总量估计"这个数 | 这个数必须 ≥ 当前叫数，且 ≥ 期望水位 |
| **3. 收网** | 他加到顶格 +1 → 果断开 | 开之前再确认一次我的有效个数 |

#### 关键风险：算错了怎么办
```plain
  顶格收网的全部风险集中在"我算错了对手的个数"

  风险场景：
    我算他 2 个，其实他有 4 个
    → 我喊 6 个 3，实际总量 8 个
    → 他加到 7 个 3，我开心地开牌 → 我输

  ▼ 风险控制三条 ▼

  「1」 只在有明确情报时用这招
     至少要有 2 个独立信号支持你的估值
     （比如：他绕开过 3 + 他犹豫过）

  「2」 估值取保守值
     如果他"可能 1 个也可能 3 个"，按 3 个算
     宁可少赚，不要翻车

  「3」 顶格数不超过 "自己的有效个数 + 3"
     2 人局对手最多 5 颗，但他不可能全中
     超过这个上限，说明你的估值已经失真
```

### 6_3 开牌决策树：开还是不开
把前面所有判断整合成一棵可执行的决策树：

```plain
  对手叫出 "N 个 X"，轮到我决策
        │
        ├─► 第一步：算出我的有效个数 E
        │
        ├─► 第二步：对手需出 D = N - E
        │
        └─► 第三步：按 D 值决策
                 │
                 ├─► D ≥ 6 ：【必开】超过物理上限，稳赢
                 │
                 ├─► D ≤ 1 ：【别开】
                 │        他只需出 1 个，做到概率 86.8%
                 │        我开牌胜率仅 13.2%
                 │
                 ├─► D = 2 ：【看情报】
                 │        纯概率五五开（我胜率 46.1%）
                 │        有明确情报支持才开
                 │
                 ├─► D = 3 ：【果断开】
                 │        他做到概率只有 21.0%
                 │        我开牌胜率 79.0%
                 │
                 └─► D ≥ 4 ：【先排除豹子】
                          有豹子信号 ──► 别开，认输或跟
                          无豹子信号 ──► 果断开，胜率 95%+
```

#### 开牌的概率速查（2 人局，对手 5 颗骰）
| 对手需出 D 个 | 他能做到的概率 | 我开牌的胜率 | 建议 |
| :---: | ---: | ---: | --- |
| 1 个 | 86.8% | **13.2%** | 绝对别开 |
| 2 个 | 53.9% | **46.1%** | 五五开，有情报才开 |
| 3 个 | 21.0% | **79.0%** | 果断开 |
| 4 个 | 4.5% | **95.5%** | 必开（除非他豹子） |
| 5 个 | 0.4% | **99.6%** | 必开（除非他超级豹子） |
| ≥6 个 | 0% | **100%** | 数学上不可能，他只有 5 颗骰，必开 |

> **硬上限提醒**：对手手上只有 5 颗骰，能贡献的有效个数上限就是 5。所以 **D ≥ 6 时，无论他是不是豹子，这个叫数都不可能成立**——直接开，稳赢。
>

> 这张表是**纯概率基准**。当有情报（他绕开过、他犹豫过）时，实际胜率还要往上加；当他有豹子信号时（板块 5），要相应下调。
>
> **最容易记错的一点**：D=1 时开牌胜率只有 13%。很多人以为"他只要出 1 个，应该不难抓"，实际恰恰相反——对手只需出 1 个时，他有 86.8% 的概率做得到，这时候开牌几乎等于送。
>

### 6_4 临界点管理：什么叫"喊到顶了"
技巧中说"感觉喊到顶了"。这个"感觉"可以量化成三个明确的临界信号：

```plain
  信号一：数字临界
    当前叫数 ≥ 期望值 + 2（2人局即 ≥ 5 个 X）
    → 已经进入危险区，再往上每一步都是真金白银

  信号二：情报临界
    我已经用递增试探摸清了他的强门
    现在的叫数正好落在他的强门上
    → 继续加只会让他更强，该换点数或开牌了

  信号三：反应临界
    他这一轮的犹豫时间明显变长（比他基准慢 1 秒以上）
    → 他在硬撑，这是开牌的最佳窗口
```

#### 临界点的三种出牌选择
```plain
  到达临界点时，我有三条路：

  ┌─────────────────────────────────────────────┐
  │  路线 A：开牌（进攻）                       │
  │  条件：D ≥ 3，或 D = 2 且有明确情报支持     │
  │  收益：直接结束，胜率可算                   │
  │  风险：算错就输这一局                       │
  ├─────────────────────────────────────────────┤
  │  路线 B：换点数脱身（保守）                 │
  │  条件：我在别的点数上有效个数更多           │
  │  操作：持平换点，叫 "N 个 Y"                │
  │  收益：把压力转回他身上                     │
  │  风险：他可能在我的新点数上也很强           │
  ├─────────────────────────────────────────────┤
  │  路线 C：顶格收网（高级）                   │
  │  条件：我算准了总量，且顶格数 ≥ 当前叫数    │
  │  操作：叫出顶格数，等他越线                 │
  │  收益：他跟或加，我都不亏                   │
  │  风险：估值错误会翻车                       │
  └─────────────────────────────────────────────┘

  优先级建议：
    有把握算准 → C 顶格收网
    D≥3（或 D=2 有情报）→ A 开牌
    我在别的门更强 → B 换点数脱身
    都不满足 → 认输，保住下一局
```

### 6_5 案例小故事：六个三的算术题
阿明和老对手单挑，最后叫到了"5 个 3"。

阿明低头看自己的牌：`1 3 3 4 6`

```plain
  我的有效个数：
    1 的个数 = 1
    3 的个数 = 2
    → 3 的有效个数 = 1 + 2 = 3 个

  对手需要出：5 - 3 = 2 个 3
```

查概率表：D=2，对手能做到 53.9%，也就是说**我开牌胜率只有 46.1%**——不到一半，单看数字这是个不该开的牌。

但阿明没有急着下结论，他先回想前几轮的情报：

+ 第 1 轮，他叫过"3 个 3"，但被我叫"3 个 4"后他立刻换到了 4 —— 说明他 3 不算强；
+ 第 2 轮，我叫"4 个 3"时，他犹豫了近两秒才换点 —— 说明他在 3 上撑不住；
+ 综合判断：他的 3 大概只有 **1 个**。

于是阿明更新了总量估计：

```plain
  总量估计 = 我的 3 个 + 他的 1 个 = 4 个

  他叫 "5 个 3"  →  需要总量 5 个，但我算只有 4 个
  → 他多半在吹，或者他自己也没算清
```

阿明果断："开。"

对手掀盅：`2 2 4 5 6` —— **一个 3 都没有，也没有 1**。全场 3 只有阿明的 2 个（他的 1 可以当 3，所以算 3 个）。叫 5 个 3 完全不成立。

**阿明赢。**

赛后阿明在复盘表里写了一句："这局赢在**把概率和情报叠加**——单看概率只有 46%，是个不该开的牌；加上情报（他绕开过 3、在 3 上犹豫过），我判断他的 3 只有 0-1 个，实际胜率被推到 85% 以上，这才值得开。"

> **启示**：概率给你的是**基准线**，情报给你的是**修正值**。高手开牌从来不是二选一，而是"概率基准 + 情报修正"的合成判断。
>

### 6_7 板块小结
**本板块要点：**

1. **总量公式**：总量估计 = 我的有效个数（精确）+ 对手推测个数（估算）。对照基准是"总骰子数 ÷ 3"。
2. **顶格收网**：算准总量后叫出顶格数，对手加到顶格+1 就开——他跟或加我都不亏。前提是估值有 2 个以上独立信号支撑，且取保守值。
3. **开牌决策树**：算出对手需出 D 个 → **D≥6 必开（超过物理上限，稳赢）**、D≤1 别开、D=2 看情报、D=3~5 果断开（D≥4 时先排除豹子）。
4. **概率速查**：2 人局对手需出 1/2/3/4/5 个时，我开牌胜率分别是 13.2% / 46.1% / 79.0% / 95.5% / 99.6%。**D≥3 才值得果断开，D≤2 时要靠情报补。**
5. **临界点三线**：数字临界（≥期望+2）、情报临界（叫到他强门上）、反应临界（他犹豫变长）。

### 7_1 为什么必须要记：记忆的三个失真
人对牌局的记忆会系统性地骗你，主要有三种失真：

```plain
  失真一：结果偏误（Outcome Bias）
    赢了的局，你会记住"我判断对了"
    输了的局，你会记住"他运气好"
    → 实际上，赢的局里你可能判断错了只是运气好
      输的局里你可能有明确失误

  失真二：峰终效应
    你只记得最后一局的高潮和结果
    中场的试探、犹豫、换点——全都模糊了
    → 而中场的那些细节，恰恰是情报的来源

  失真三：自我美化
    三个月后回想，你记得的是"我那晚读得挺准"
    → 实际上准确率可能只有五成

  ▼ 唯一的解药 ▼
  当场写下，事后对照
```

### 7_2 局中速记：3 秒抓一条情报
#### 核心原则：局中不记全，只记三类东西
```plain
  局中速记只抓三样：

    ┌───────────────────────────────────────────┐
    │  「1」 数字：他叫了什么、我判断他需出几个     │
    │  「2」 反应：时延（快/中/慢）、加码还是换点   │
    │  「3」 结论：一句话推断（他 X 多 / 他撑不住） │
    └───────────────────────────────────────────┘

  不记：过程描述、情绪、废话
  原因：局中时间只有 3-5 秒，记多了会暴露你在记
```

#### 速记符号体系（关键：短、只有你自己懂）
| 符号 | 含义 |
| --- | --- |
| `3「2」` | 叫了 3 个 2 |
| `▲` | 秒接（<0.8 秒） |
| `●` | 正常（0.8-2 秒） |
| `▼` | 犹豫（>2 秒） |
| `+` | 加个数 |
| `→` | 换点数 |
| `×` | 开牌 |
| `*` | 我方判断（后面跟结论） |
| `!` | 重要情报，复盘时必看 |

**示例一行速记：**

```plain
  3「2」▲+ 4「2」▼+ 5「2」*他2撑住? ×赢

  解读：叫3个2 → 他秒接并加个数到4个2
        → 我叫5个2，他犹豫后仍加
        → 我判断他2可能真多
        → 我开牌，赢了
        （说明他的犹豫是演的，或者他硬撑）
```

#### 三种速记载体（按场景选）
```plain

  │  方案：预设好表格模板，每局结束复制一行填       │
  │  优点：信息完整，可直接导出                     │
  │  注意：不要在对局进行中频繁打字（会被看穿）     │
  │       只在"轮到别人叫数"或"自然间隙"时补记      │
  ├─────────────────────────────────────────────────┤
  │  场景二：酒桌、不宜拿手机                       │
  │  载体：默记 + 局后立即补                        │
  │  方案：每局结束只记一句话"关键词"               │
  │       例："3「2」 他秒接 我开赢"                    │
```

### 7_6 案例小故事：一本笔记带来的翻盘
小郑和同事老王每周五都要喝几杯、摇几把骰子。前两个月，小郑**几乎没赢过**。

从第三个月开始，小郑养成了一个习惯：每次散场后花 5 分钟在手机里记几行。三个月后，他给老王建了这样一份档案：

```plain
  老王：B攻击型，老手
  强门：偏好 4 和 6（敢在这两个点数上加码）
  开牌意愿：高（爱开牌）
  表演：会装弱，犹豫 2-3 秒后加码
  关键发现：他装弱时，会不自觉地用手指敲桌子！
  克制方法：看到他敲桌子 = 他有牌，千万别开
            他真没牌时反而很安静
```

这个"敲桌子"的细节，是小郑在第 6 次复盘时偶然发现的——他发现老王有牌装弱的三次，都在敲桌子。

从那以后，小郑对老王的胜率从三成涨到了**七成**。

> **启示**：档案的价值不在"记了多少局"，而在**从重复中提炼出别人自己都没意识到的习惯**。这种"他自己都不知道的破绽"，一旦被你抓住，就很难改掉——因为人不会改掉一个自己没意识到的动作。
>

### 7_8 板块小结
**本板块要点：**

1. **记忆会骗你**：结果偏误、峰终效应、自我美化，三种失真决定了必须当场记。
2. **局中只记三样**：数字、反应、一句话结论。用速记符号体系压缩到 3 秒内完成。按场景选载体（手机 / 默记 / 分栏表）。

4. **对手档案**：最值钱的复利资产。第 1 次记行为、第 3 次定类型、第 5 次总结克制方法。重点捕捉"他自己都没意识到的习惯"。

### 8_1 概率验证实验：亲手跑一遍，把数字刻进脑子

#### 实验 A：手工掷骰 100 次（零门槛）

#### 实验 C：代码模拟 10 万局（最精确，推荐）
如果想一次跑出精确结果，可以用下面的脚本。复制粘贴到任意 Python 环境即可运行（无需安装任何库）。

```python
import random
from collections import Counter

def roll(n=5):
    """摇 n 颗骰子，返回点数列表"""
    return [random.randint(1, 6) for _ in range(n)]

def effective_count(dice, target):
    """计算 target 点数的有效个数（1 为万能）"""
    return sum(1 for d in dice if d == target or d == 1)

def simulate_two_player(rounds=100000):
    """模拟 2 人局：验证各叫数的达标概率"""
    result = {k: 0 for k in range(1, 10)}
    for _ in range(rounds):
        me = roll(5)
        opp = roll(5)
        total = effective_count(me, 3) + effective_count(opp, 3)
        for k in range(1, 10):
            if total >= k:
                result[k] += 1
    print("=== 2人局(10颗) 叫 N 个 X 的达标概率 ===")
    for k in range(1, 10):
        print(f"  {k} 个 X: {result[k]/rounds*100:5.2f}%")

def simulate_call_one(rounds=100000):
    """模拟 2 人局叫 1（1 不万能）"""
    result = {k: 0 for k in range(1, 8)}
    for _ in range(rounds):
        me = roll(5)
        opp = roll(5)
        total = me.count(1) + opp.count(1)
        for k in range(1, 8):
            if total >= k:
                result[k] += 1
    print("\n=== 2人局(10颗) 叫 N 个 1 的达标概率 ===")
    for k in range(1, 8):
        print(f"  {k} 个 1: {result[k]/rounds*100:5.2f}%")

def simulate_need(rounds=100000):
    """对手 5 颗骰中，至少出 D 个 X 的概率（用于开牌决策）"""
    print("\n=== 对手5颗骰，至少出 D 个 X(含万能1)的概率 ===")
    for D in range(0, 6):
        cnt = 0
        for _ in range(rounds):
            if effective_count(roll(5), 3) >= D:
                cnt += 1
        print(f"  至少 {D} 个: {cnt/rounds*100:5.2f}%"
              f"   → 我开牌胜率 {100-cnt/rounds*100:5.2f}%")

def simulate_baozi(rounds=100000):
    """个人豹子概率：某点数有效个数 >= k"""
    print("\n=== 个人5颗骰，某点数有效个数 >= k 的概率 ===")
    for k in range(2, 6):
        cnt = 0
        for _ in range(rounds):
            dice = roll(5)
            best = max(effective_count(dice, t) for t in range(2, 7))
            if best >= k:
                cnt += 1
        print(f"  >= {k} 个: {cnt/rounds*100:5.2f}%")

if __name__ == "__main__":
    simulate_two_player()
    simulate_call_one()
    simulate_need()
    simulate_baozi()
```

### 8_2 心理博弈验证清单：技巧有没有真的用对
概率可以用代码验证，心理博弈只能靠**对照记录**。下面按技巧逐条给出验证方法。

#### 验证表：九条技巧的实操对照
| # | 技巧 | 验证方法 | 达标标准 |
| :---: | --- | --- | --- |
| 「1」 | 首轮逆叫 | 记录 20 局首轮叫数，统计"叫了最弱门"的比例 | ≥80% 的局执行了逆叫 |
| 「2」 | 响应时延读心 | 记录 20 次"时延判断 vs 实际牌力" | 准确率 ≥60% |
| 「3」 | 递增试探 | 记录 10 局是否推断出对手强门 | ≥7 局推断成功 |
| 「4」 | 摇摆识别 | 记录 15 次"摇摆/死守"判断与实际对照 | 准确率 ≥65% |

| 「6」 | 强牌装弱 | 记录 20 次装弱，统计对手开牌比例 | ≥50% 能诱开 |

| 「9」 | 老手首轮 | 记录 15 次对老手的首轮开牌 | 满足条件时胜率 ≥70% |

#### 单一技巧的 A/B 验证法
想验证某个技巧到底有没有用，最干净的方法是**交替使用**：

```plain
  以"强牌装弱"为例：

    第 1、3、5、7 局（A 组）：使用强牌装弱
    第 2、4、6、8 局（B 组）：正常叫数，不演

    各打 10 局后，比较两组的胜率

  ┌────────────────────────────────────────┐
  │  A组(装弱)： ____ 胜 / 10 局  = ____%  │
  │  B组(不演)： ____ 胜 / 10 局  = ____%  │
  │                                        │
  │  差值：______ 个百分点                 │
  └────────────────────────────────────────┘

  ⚠ 注意：
    10 局的样本量很小，差值在 20 个百分点以内
    都可能是随机波动，不要急着下结论
    建议至少各累计 20 局再判断
```

#### 反向验证：找出你的"假优势"
```plain
  很多人以为自己某项很强，其实是错觉。
  用这个方法排查：

    1. 列出你自认为最强的三项技巧
    2. 为每一项建立一个 20 局的记录
    3. 统计真实准确率
```

### 8_5 案例小故事：数据打脸的一晚
阿康学完这套体系，自我感觉良好，觉得自己"读人特别准"。

板块 8 的"反向验证"要求他做 20 局记录，他老老实实做了。结果显示：

```plain
  自认为最强的"读心"能力：
    20 次判断，对了 11 次
    准确率 55%

  抛硬币的准确率是 50%
```

也就是说，他引以为傲的读心术，实际效果**比抛硬币好一点点**。

这个数据让他很不舒服，但也让他找到了真正的问题：他所谓的"读心"，其实是在**猜**，而不是基于"时延 + 加码幅度 + 换点数"的综合判断。

接下来一个月，他强迫自己每次判断都必须说出**至少两个依据**（比如"他犹豫了 + 他绕开过这个点数"）。一个月后再统计：

```plain
  20 次判断，对了 14 次
  准确率 70%
```

从 55% 到 70%，靠的不是"更有感觉"，而是**把感觉拆成可检查的依据**。

> **启示**：数据会打脸，但打脸是好事。你以为的强项如果不是真的强项，那它就是你最大的提升空间——而在这之前，你甚至不知道该练什么。
>

### 8_6 板块小结
**本板块要点：**

1. **概率可验证**：三个实验任选其一——手工 100 次、10 颗骰 100 次、代码 10 万局（推荐，脚本可直接运行）。跑一遍比看十遍记得牢。
2. **心理博弈靠对照**：九条技巧各有验证方法和达标线。想验证单一技巧，用 A/B 交替法，但样本要够（各 20 局以上）。
3. **警惕假优势**：自认为最强的三项，一定要用 20 局数据检验。常见假优势是"我很会读人"（实测 52%）。
4. **30 天计划**：地基周（概率）→ 感知周（读心+记录）→ 表演周（演技+节奏）→ 收网周（算力+档案）。每天有明确产出和达标标准。
5. **里程碑追踪**：每月更新 M1-M4 进度，用数据而非感觉判断进步。

### 9_2 常见误区清单：这十个坑最贵
#### 误区一：把"1 多"当成好事
```plain
  错误认知：我 1 多 = 我万能牌多 = 我强
  实际情况：1 多意味着你每个点数都有保底，
            但没有绝对强门（摇摆型特征，见板块3）

  正确做法：1 多时，走"稳"的路线
            别指望靠某一门爆发，
            而是靠"每门都有保底"慢慢推高
```

#### 误区二：看到大数字就慌
```plain
  错误认知：他叫 7 个 X，我手上 0 个，肯定输定了
  实际情况：他手上只有 5 颗骰，最多贡献 5 个。
            我手上 0 个时，D = 7 - 0 = 7 ≥ 6，
            **这个叫数在数学上根本不可能成立**——
            不是他太强，是他吹过了物理上限，直接开就赢

  正确做法：先算 D = 他叫的数 - 我的有效个数
            D ≥ 6 → 必开，稳赢
            D = 2~3 → 按板块 5 的"三不原则"，不慌、不硬顶
```

#### 误区三：开牌靠"感觉他心虚"
```plain
  错误认知：我看他眼神闪烁，肯定在吹
  实际情况：眼神是最不可靠的信号，
            老手会专门练这个

  正确做法：开牌必须有数字依据
            （算出 D 值）或明确情报
            （他绕开过 / 他犹豫过 / 他跳叫过）
```

#### 误区四：认为"逆叫"就是随便乱叫
```plain
  错误认知：反正要虚张，那就叫个离谱的
  实际情况：逆叫有上限 —— 期望水位 + 1
            超过就是送人头

  正确做法：逆叫只在"叫数的点数"上做文章，
            个数仍要守住水位
```

#### 误区五：装弱时不看对象
```plain
  错误认知：强牌就要装弱，肯定能诱他开
  实际情况：对手如果是死也不开的保守型，
            你装得再像也是白演

  正确做法：先判断对手的"开牌意愿"
            （板块 5 的对手档案卡），
            再决定装弱还是强攻
```

#### 误区六：赢了就膨胀，输了就急躁
```plain
  错误认知：手感来了，多叫点没关系
  实际情况：膨胀会让你跳过计算步骤，
            急躁会让你泄露反应

  正确做法：无论输赢，保持决策节奏一致
            这是防止被读的根本方法
```

#### 误区七：只记自己的牌，不看对手
```plain
  错误认知：我先把自己算清楚就行
  实际情况：自己的牌是固定信息，
            对手的牌才是变量

  正确做法：70% 注意力放对手身上
            每轮至少记一条他的行为情报
```

#### 误区八：跳过复盘
```plain
  错误认知：打多了自然就强了
  实际情况：不复盘的"经验"只是重复错误
            而且记忆会系统性地美化你

  正确做法：散场后 10 分钟，
            至少回答"三问"（板块 7）
```

#### 误区九：用同一套打法打所有人
```plain
  错误认知：我这套打法很稳，谁都能用
  实际情况：对保守型有效的"气势压制"，
            对攻击型就是送菜

  正确做法：先分类（板块 5 四象限），
            再选剧本
```

#### 误区十：把技巧当秘籍，忽略概率底盘
```plain
  错误认知：背下九条口诀就能赢
  实际情况：没有概率打底的表演叫瞎蒙

  正确做法：先花一周背水位表（板块 1），
            再练演技（板块 4）
```

### 9_6 板块小结与全书收尾
**本板块要点：**

1. **速查卡**：概率底表（70/44/21/8）、九条口诀、开牌三步（算 E → 算 D → 查表）、四类对手出招、保命三条。建议截图存手机。
2. **十大误区**：最贵的三个是——把 1 多当好事、开牌靠感觉、跳过复盘。
3. **速查索引**：按局面反查技巧和板块，遇到具体情况直接定位。
4. **酒桌分寸**：游戏是助兴的，别用来劝酒，看场合调整火力。

**全书收尾：**

这本手册把经典技巧的九条经验，拆成了**概率、读心、表演、算力、记录**五层能力。九条口诀是前辈的经验总结，但它们之所以成立，是因为背后有清晰的数学和心理学支撑。

当你理解了"为什么"，这些技巧就不再是需要死记的口诀，而是可以**按局面重新组合**的工具。这才是从"背攻略"到"会打牌"的真正跨越。

最后提醒一句：骰子的魅力在于不确定性。把所有技巧都算尽，反而会失去一点乐趣——**算得清的时候认真算，算不清的时候坦然认**，这才是酒桌上最好的状态。

祝玩得开心。
